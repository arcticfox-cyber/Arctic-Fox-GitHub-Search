------------------------------------------------------------
ABOUT
------------------------------------------------------------

Arctic Fox is a Python-based GitHub search and inspection
tool designed for Kali Linux and other Linux distributions.

It allows users to search GitHub accounts, explore public
repositories, view profile information, inspect repository
details, clone repositories and generate text reports.

------------------------------------------------------------
FEATURES
------------------------------------------------------------

[+] GitHub Username Search
[+] Public Profile Information
[+] Public Repository Explorer
[+] Repository Stars and Forks
[+] Programming Language Information
[+] Repository Topics
[+] Repository Details
[+] Repository Cloning
[+] Open Profiles in Browser
[+] Public Gist Explorer
[+] Organization Information
[+] Recent Public Activity
[+] Text Report Generator
[+] GitHub API Token Configuration
[+] Custom Repository Clone Directory
[+] Animated Terminal Interface

------------------------------------------------------------
REQUIREMENTS
------------------------------------------------------------

- Kali Linux or Linux
- Python 3
- Git
- Internet Connection

------------------------------------------------------------
INSTALLATION
------------------------------------------------------------

Step 1: Clone Repository

git clone https://github.com/arcticfox-cyber/Arctic-Fox-GitHub-Search-v3.0.git

Step 2: Enter Directory

cd Arctic-Fox-GitHub-Search-v3.0

Step 3: Install Requirements

sudo apt update
sudo apt install python3 git -y

Step 4: Give Permission

chmod +x arcticfox.py

Step 5: Install Arctic Fox

sudo install -m 755 arcticfox.py /usr/local/bin/arcticfox

Step 6: Create Short Command

sudo ln -sf /usr/local/bin/arcticfox /usr/local/bin/af

------------------------------------------------------------
USAGE
------------------------------------------------------------

Start Arctic Fox:

af

Search a GitHub username:

af arcticfox-cyber

Search another account:

af octocat

------------------------------------------------------------
AVAILABLE OPTIONS
------------------------------------------------------------

[1] Clone Repository
[2] Repository Details
[3] Open Repository in Browser
[0] Back

------------------------------------------------------------
SETTINGS
------------------------------------------------------------

Open settings:

s

Available settings:

[1] Set or Clear GitHub API Token
[2] Change Repository Clone Directory
[0] Back

------------------------------------------------------------
REPORT GENERATOR
------------------------------------------------------------

Arctic Fox can generate text reports containing:

- Profile Information
- Public Repositories
- Stars and Forks
- Programming Languages
- Repository Descriptions
- Repository Topics
- Public Gists
- Recent Public Activity

Reports are saved in:

~/arctic-fox-reports/

------------------------------------------------------------
CONFIGURATION
------------------------------------------------------------

Configuration File:

~/.config/arctic-fox/config.json

GitHub API Token is optional.

------------------------------------------------------------
IMPORTANT NOTES
------------------------------------------------------------

- Internet connection is required.
- GitHub API rate limits may apply.
- Only publicly available information is retrieved.
- Repository cloning requires Git.
- Maximum repository listing: 600 repositories.
